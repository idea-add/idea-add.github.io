## 한눈에 보는 정의

**Data Drift**(데이터 드리프트)는 시간이 지나면서 실제 데이터의 패턴이 모델을 학습시킬 때와 달라져, 예측 성능이 점점 떨어지는 현상을 뜻합니다.

## 자세히 알아보기

- 예문: "코로나 이전 소비 패턴으로 학습한 예측 모델은, 이후 소비 행태가 크게 바뀌며 **Data Drift**로 인해 정확도가 눈에 띄게 떨어졌다."
- 모델은 학습 당시의 데이터를 기준으로 패턴을 익히는데, 시간이 지나며 고객의 행동이나 시장 상황이 바뀌면 이제는 맞지 않는 낡은 패턴을 기준으로 계속 예측하게 되어 성능이 저하됩니다.
- 이 문제를 미리 알아채려면, 실제 운영 중인 모델의 입력 데이터 분포를 지속적으로 {{< term "monitoring" >}}(모니터링)하며 학습 당시와 얼마나 달라졌는지 확인해야 합니다.
- Data Drift가 감지되면, 최신 데이터를 반영해 모델을 다시 학습시키는 과정이 필요하며, 이런 재학습 주기를 어떻게 관리할지가 실제 운영 환경에서 중요한 과제로 다뤄집니다.
