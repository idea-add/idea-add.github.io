## 한눈에 보는 정의

**ODS**(Operational Data Store, 운영 데이터 저장소)는 여러 운영 시스템의 데이터를 가공 없이 가져와, 데이터 웨어하우스에 넣기 전 한곳에 모아두는 중간 저장소입니다.

## 자세히 알아보기

- 예문: "여러 시스템의 데이터를 각각 조회하기 번거로워, 일단 원본 그대로 **ODS**에 모아둔 뒤 여기서 가공해 **DWH**로 보냈다."
- {{< term "dwh" >}}(DWH)에 데이터를 넣기 전, 정제·변환된 형태가 아니라 원본에 가까운 형태로 최신 데이터를 한곳에 모아둔다는 점에서 완성된 데이터 웨어하우스와는 성격이 다릅니다.
- 여러 시스템의 최신 데이터를 통합해서 봐야 하는 운영 부서의 실무 조회 용도로도 활용되며, {{< term "etl" >}}(ETL) 과정의 중간 단계 저장소 역할도 겸합니다.
- 오래된 이력을 두고두고 보관하는 DWH와 달리, ODS는 최신 상태 위주로 유지되며 상대적으로 짧은 주기로 데이터가 갱신되는 경우가 많습니다.
