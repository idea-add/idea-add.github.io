## 한눈에 보는 정의

**Data Mesh**(데이터 메시)는 데이터를 중앙 조직이 독점 관리하는 대신, 각 도메인 팀이 자신의 데이터를 하나의 제품처럼 책임지고 관리하는 분산형 데이터 관리 철학입니다.

## 자세히 알아보기

- 예문: "모든 요청이 중앙 데이터팀에 몰려 병목이 심해지자, 각 사업부가 자기 데이터를 직접 책임지는 **Data Mesh** 방식으로 전환했다."
- 조직이 커질수록 하나의 중앙 데이터팀이 모든 도메인의 데이터를 이해하고 관리하기 어려워지는데, Data Mesh는 그 도메인을 가장 잘 아는 팀에게 데이터의 품질과 제공 책임을 넘겨 이 병목을 해소합니다.
- 각 팀은 자신의 데이터를 다른 팀이 쉽게 찾고 신뢰해서 쓸 수 있도록, 일종의 '제품'처럼 문서화하고 품질을 관리해야 한다는 책임을 함께 갖습니다.
- 이렇게 분산된 데이터가 서로 다른 기준으로 관리되지 않도록, 전사 차원의 공통 {{< term "data-governance" >}}(데이터 거버넌스) 원칙은 여전히 함께 필요합니다.
