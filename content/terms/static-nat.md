## 한눈에 보는 정의

**Static NAT**(정적 NAT)는 하나의 내부 IP 주소를 항상 같은 하나의 외부 IP 주소로 고정해 변환하는 {{< term "nat" >}}(NAT) 방식입니다.

## 자세히 알아보기

- 예문: "외부에서 사내 웹 서버에 항상 같은 주소로 접속할 수 있도록, 그 서버에는 **Static NAT**를 적용해 외부 IP를 고정했다."
- 내부 IP와 외부 IP가 1대1로 항상 똑같이 매칭되기 때문에, 외부에서 특정 내부 서버에 지속적으로 접근해야 하는 경우(웹 서버, 메일 서버 등)에 적합합니다.
- 매번 다른 외부 주소를 할당하는 {{< term "dynamic-nat" >}}(Dynamic NAT)와 달리, 하나의 공개 IP 주소를 그 서버만을 위해 전용으로 써야 해 IP 주소를 효율적으로 아끼기는 어렵습니다.
- 접근 대상과 주소가 고정되어 있어 관리와 추적이 간단하지만, 그만큼 공개 IP 주소가 서버 수만큼 필요하다는 점이 한계로 꼽힙니다.
