## 한눈에 보는 정의

**L7**(Layer 7, 7계층 로드밸런싱)은 URL이나 쿠키처럼 요청 내용까지 분석해, 더 정교한 기준으로 트래픽을 분산하는 {{< term "application-layer" >}}(애플리케이션계층) 로드밸런싱 방식입니다.

## 자세히 알아보기

- 예문: "이미지 요청과 API 요청을 서로 다른 서버로 나눠 처리하기 위해, URL 경로를 분석할 수 있는 **L7** 로드밸런서를 도입했다."
- 단순히 IP와 포트만 보는 {{< term "l4" >}}(L4)와 달리, HTTP 요청의 URL 경로, 쿠키, 헤더 내용까지 들여다보고 이에 맞춰 서로 다른 서버 그룹으로 트래픽을 나눌 수 있습니다.
- 예를 들어 '/images'로 시작하는 요청은 이미지 전용 서버로, '/api'로 시작하는 요청은 API 서버로 보내는 식의 세밀한 라우팅이 가능해, 여러 서비스로 기능이 나뉜 구조에서 특히 유용합니다.
- 요청 내용을 분석하는 만큼 L4보다 처리 부하가 크지만, 그만큼 트래픽 특성에 맞춘 유연한 분산 전략을 짤 수 있다는 장점이 있습니다.
