## 한눈에 보는 정의

**Reference Data**(참조 데이터)는 국가 코드, 통화 코드처럼 여러 시스템이 공통으로 참조하며, 자주 바뀌지 않는 표준화된 값의 목록을 뜻합니다.

## 자세히 알아보기

- 예문: "여러 시스템이 국가를 서로 다른 이름으로 기록하고 있어, 표준화된 **Reference Data**로 국가 코드를 통일했다."
- 고객이나 주문처럼 계속 새로 생기고 바뀌는 데이터와 달리, 국가 코드나 통화 코드 같은 참조 데이터는 오랫동안 거의 변하지 않고 여러 시스템에서 공통 기준으로 활용됩니다.
- 시스템마다 참조 데이터를 서로 다르게 관리하면 같은 값을 다르게 해석하는 문제가 생길 수 있어, 이를 하나로 통일해 관리하는 것도 {{< term "master-data-management" >}}(MDM)의 한 부분으로 다뤄집니다.
- 데이터를 분석할 때도 참조 데이터를 기준으로 삼아 서로 다른 시스템의 값을 매칭하고 통합하는 경우가 많아, {{< term "data-integration" >}}(데이터 통합) 작업의 중요한 기준점이 됩니다.
