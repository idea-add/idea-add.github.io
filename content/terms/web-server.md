## 한눈에 보는 정의

**Web Server**(웹 서버)는 브라우저의 요청을 받아 HTML, 이미지 같은 정적 콘텐츠를 응답으로 돌려주는 서버 소프트웨어입니다.

## 자세히 알아보기

- 예문: "정적 파일은 **Web Server**가 직접 처리하고, 로그인처럼 데이터베이스 조회가 필요한 요청만 뒤에 있는 **WAS**로 넘긴다."
- {{< term "http" >}}(HTTP) 프로토콜을 이해하고, 요청받은 파일을 그대로 찾아 돌려주는 단순하고 빠른 처리에 특화되어 있어, 정적 콘텐츠 서빙에서는 웹 서버가 애플리케이션 서버보다 효율적입니다.
- 로그인, 결제처럼 프로그램 로직과 데이터베이스 처리가 필요한 동적 요청은 웹 서버가 직접 처리하지 않고 {{< term "was" >}}(WAS, 애플리케이션 서버)로 전달해 처리하도록 역할을 나눕니다.
- {{< term "reverse-proxy" >}}(리버스 프록시) 역할까지 겸해, 여러 대의 WAS 앞단에서 트래픽을 분산하는 창구 역할을 하는 것이 일반적인 구성입니다.
