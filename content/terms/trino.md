## 한눈에 보는 정의

**Trino**(트리노)는 {{< term "presto" >}}(Presto) 프로젝트에서 갈라져 나온 분산 SQL 분석 엔진으로, 여러 데이터 소스를 하나의 SQL 질의로 한 번에 조회할 수 있게 해줍니다.

## 자세히 알아보기

- 예문: "이 회사는 여러 데이터 소스를 넘나드는 분석 요구가 많아, 활발한 오픈소스 커뮤니티가 이끄는 **Trino**를 조회 엔진으로 선택했다."
- 이름과 소속 조직이 달라졌을 뿐, 여러 데이터 소스에 커넥터로 접속해 하나의 SQL 질의로 함께 조회할 수 있게 해준다는 핵심 개념은 Presto와 근본적으로 같은 계보를 잇고 있습니다.
- 서로 다른 프로젝트로 갈라진 이후에도 각자 독자적으로 발전해오고 있어, 실제 도입 시에는 두 프로젝트의 최신 기능과 커뮤니티 활성도를 비교해 선택하는 경우가 많습니다.
- {{< term "data-lake" >}}(데이터 레이크)나 {{< term "data-lakehouse" >}}(데이터 레이크하우스) 환경에서, 다양한 형태로 저장된 데이터를 SQL 하나로 통합 조회하는 핵심 엔진으로 자주 채택됩니다.
