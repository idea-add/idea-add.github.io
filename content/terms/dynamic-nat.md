## 한눈에 보는 정의

**Dynamic NAT**(동적 NAT)는 여러 개의 내부 IP 주소를, 그보다 적은 수의 외부 IP 주소 풀에서 필요할 때마다 하나씩 빌려와 변환하는 {{< term "nat" >}}(NAT) 방식입니다.

## 자세히 알아보기

- 예문: "내부 직원 100명이 쓰는 PC에, 공개 IP 주소 20개로 구성된 풀을 두고 **Dynamic NAT**로 필요할 때마다 하나씩 빌려 쓰게 했다."
- 모든 내부 PC가 동시에 인터넷을 쓰는 것은 아니기 때문에, 내부 IP 수보다 적은 공개 IP만 확보해두고 그 순간 필요한 PC에만 임시로 할당하는 방식으로 공개 IP를 절약할 수 있습니다.
- 고정된 하나의 외부 주소를 계속 쓰는 {{< term "static-nat" >}}(Static NAT)와 달리, 어떤 내부 IP가 어떤 외부 IP를 쓰게 될지는 그때그때 바뀔 수 있어 외부에서 특정 서버로 꾸준히 접근해야 하는 용도에는 적합하지 않습니다.
- 그래도 풀에 있는 외부 IP 수만큼만 동시에 외부 통신이 가능해, 사용자가 매우 많은 조직에서는 훨씬 더 많은 내부 주소를 단 하나의 외부 IP로 변환하는 {{< term "pat" >}}(PAT)를 함께 쓰는 경우가 많습니다.
