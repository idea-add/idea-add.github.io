## 한눈에 보는 정의

**Middleware**(미들웨어)는 운영체제와 애플리케이션 사이, 또는 서로 다른 애플리케이션 사이에서 데이터 교환과 공통 기능을 대신 처리해주는 소프트웨어를 뜻합니다.

## 자세히 알아보기

- 예문: "여러 시스템을 직접 일일이 연결하는 대신, **Middleware**를 두어 데이터 형식 변환과 중계를 한곳에서 처리하도록 했다."
- {{< term "was" >}}(WAS)도 애플리케이션이 운영체제나 데이터베이스와 직접 통신하지 않고도 동작할 수 있게 해주는 대표적인 미들웨어의 한 종류로 분류됩니다.
- 서로 다른 시스템을 연결해 데이터를 주고받게 해주는 {{< term "eai" >}}(EAI)나 메시지를 중계하는 {{< term "message-broker" >}}(메시지 브로커)도 넓은 의미의 미들웨어에 속합니다.
- 애플리케이션 개발자가 인증, 로깅, 트랜잭션 관리 같은 공통 기능을 매번 새로 만들지 않아도 되게 해줘, 개발 생산성과 시스템 간 호환성을 높이는 역할을 합니다.
