## 한눈에 보는 정의

**Reverse Proxy**(리버스 프록시)는 클라이언트의 요청을 대신 받아, 뒤에 있는 여러 내부 서버 중 알맞은 곳으로 전달해주는 서버 쪽 중계 서버입니다.

## 자세히 알아보기

- 예문: "사용자는 하나의 도메인으로 접속하지만, 실제로는 **Reverse Proxy**가 요청 종류에 따라 여러 내부 서버로 트래픽을 나눠 전달한다."
- 클라이언트를 대신해 외부에 요청을 보내는 {{< term "proxy" >}}(프록시)와 반대로, Reverse Proxy는 서버 쪽에 위치해 외부에서 오는 요청을 대신 받아 내부의 실제 서버로 전달해준다는 점이 다릅니다.
- 내부 서버의 실제 주소와 구조를 외부에 노출하지 않아도 되어 보안에 유리하고, {{< term "l7" >}}(L7) 로드밸런싱 기능까지 함께 수행하는 경우가 많습니다.
- 널리 쓰이는 {{< term "web-server" >}}(웹 서버) 소프트웨어들은 정적 파일을 직접 처리하는 동시에, 동적 요청은 뒤에 있는 {{< term "was" >}}(WAS)로 넘겨주는 Reverse Proxy 역할을 함께 수행하는 구성이 일반적입니다.
